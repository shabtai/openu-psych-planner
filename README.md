# מתכנן תואר ראשון בפסיכולוגיה — האוניברסיטה הפתוחה (חד-חוגי)

אפליקציית מעקב ותכנון לתואר ראשון בפסיכולוגיה (חד-חוגי, תכנית 48) באוניברסיטה הפתוחה.
קובץ HTML יחיד, ללא שרת וללא התקנה — הנתונים נשמרים מקומית בדפדפן (localStorage).

**שימוש חי:** https://shabtai.github.io/openu-psych-planner/

## יכולות
- כל הקורסים מתכנית הלימודים הרשמית (תשתית, חובה, בחירה, אשכולות מתקדמים, סמינריונים, בחירה חופשית, דרישות כלליות).
- שלושה מצבים לכל קורס: ✅ סיימתי · 📖 בלימוד כעת · 📅 מתוכנן לסמסטר הבא.
- חישוב חי: כמה נ"ז הושלמו, כמה בלימוד, כמה מתוכננים וכמה נותרו (מתוך 120, ובהן 24 מתקדמות).
- מעקב ציונים + ממוצע משוקלל (GPA).
- פאנל "מה נשאר?" ופאנל הסמסטרים (נוכחי/הבא).
- כפתור "סיום סמסטר" שמגלגל קדימה: בלימוד → הושלם, מתוכנן → בלימוד.
- גיבוי/ייבוא JSON והדפסה.

> מבוסס על תכנית הלימודים הרשמית (ידיעון תשפ״ז). לאימות סופי יש לפנות לייעוץ האקדמי של האו״פ.
